Pressure Ulcer Risk Prediction System
(ระบบประเมินความเสี่ยงแผลกดทับ)

System Description (คำอธิบายระบบ)

ระบบนี้ช่วยประเมินความเสี่ยงการเกิดแผลกดทับจากมุมการนอนและน้ำหนักตัวของผู้ป่วยติดเตียง โดยใช้แบบจำลองทางคณิตศาสตร์ในการคำนวณแรงกดและแรงเฉือน พร้อมแนะนำการปรับมุมเตียงเพื่อลดความเสี่ยงในการเกิดแผลกดทับ รวมถึงแสดงกราฟแนวโน้มการใช้งานและเก็บข้อมูลย้อนหลังของผู้ใช้งานแต่ละคน

This system evaluates pressure ulcer risk based on bed angle and patient body weight using mathematical modeling. The system calculates pressure and shear forces, provides posture adjustment recommendations, and displays usage trends and patient history.
